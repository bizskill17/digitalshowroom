# Digital Showroom

**Create your Digital Showroom** — a WhatsApp-first product showroom for small sellers.

## What it does

- Logo, shop name and tagline at the top, with a shareable showroom link
- Multiple catalogues (e.g. Full menu, Party & gifting, School orders)
- Products and product categories, each with a featured picture
- Select items with quantity; WhatsApp buttons with prefilled messages:
  - **Send us these items** (order list with estimated total)
  - **Get quotation** (for bulk / price-on-request items)
- WhatsApp Status pictures: tick products, every 6 products make one picture, each with a QR code; save, copy or download all as ZIP
- Customer buttons: **Download catalogue** (PDF), **Save card** (business card PNG), **Save contact** (.vcf)

## Files

- `index.html` — the current single-page demo (sample shop: Bliss Bites, placeholder prices)

## Run it

Open `index.html` in a browser, or upload it to any static host (e.g. Hostinger `public_html`).
It loads QR, PDF and ZIP libraries from cdnjs.
